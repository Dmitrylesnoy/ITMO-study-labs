ЛР №3 — вариант 22/7

Дискретно-событийные эксперименты
1. Распакуйте архив. Нужен Python с NumPy.
2. Запустите python sim.py в папке архива.
3. results.json будет перезаписан результатами, включая сырые выборки для гистограмм.
   В исходном архиве results.json содержит агрегаты, а histogram_fits.json — параметры
   сравнения положительных частей выборок.

Обозначения
E — экспоненциальный закон, K — Эрланг-2, H — гиперэкспоненциальный (КВ 2),
T — трасса, A — гипоэкспоненциальная аппроксимация, U — равномерный,
D — детерминированный поток. rho — загрузка, lq — длина очереди,
ln — число заявок, x — производительность, w — ожидание, t — пребывание.
Индекс n в xn, wn, tn обозначает узловую характеристику.

Листинги для GPSS World
system1.gpss.txt — двухканальная СИСТЕМА_1.
closed.gpss.txt — замкнутая сеть М2.
open.gpss.txt — разомкнутая сеть М2.
Создайте объект Model, вставьте текст модели и выберите Command → Create Simulation.
Настройки: Flow и Mode для СМО, Npop или Gap и Mode для сети.
Если GPSS требует более коротких строк, разбейте формулы через отдельные VARIABLE.
Листинги подготовлены для проверки в GPSS World. Прогоны для отчёта выполнены на Python.
