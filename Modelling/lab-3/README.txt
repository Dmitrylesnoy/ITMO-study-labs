ЛР №3. Вариант A=22, B=7. Все новые имитационные эксперименты выполнены в GPSS World Student.
Актуальный отчёт: ЛР3_Моделирование_Вариант22_7_GPSS.docx.

Быстрый запуск
1. В GPSS World выбрать File → Open и открыть gpss/models/system1.gps.
2. Выбрать Command → Create Simulation. Команды START уже включены в модель.
3. Дождаться окончания прогонов. Открыть стандартный Report и Journal.
Аналогично: closed.gps — замкнутая сеть, open.gps — разомкнутая сеть.
closed_histogram.gps — демонстрационный прогон сети с гиперэкспоненциальным узлом 1.

Полные серии
smo_repeats.gps — основные исследования СМО, три независимых повтора, переходный режим.
warm_interval_series.gps — переходный режим при изменении входного интервала.
pool_series.gps — отдельная общая очередь, изменение числа приборов и проверка M/G/1.
network_series.gps — замкнутая сеть, разгрузка узла 4, открытая нагрузочная кривая.
paired_series.gps — открытые сети при интенсивностях, равных производительности замкнутых.
Полные серии могут работать заметно дольше отдельных демонстрационных моделей.

предоставленных данных сначала скопируйте results. На другом компьютере измените пути
OPEN в модели перед Create Simulation. Текстовые .txt дублируют исходники .gps;
это текст для копирования в объект Model, не файлы для команды INCLUDE.

Результаты и происхождение данных
Номер_1.txt — измерительный этап; номер_0.txt — разогрев, если предусмотрен.
experiments.json: сеть, для отчёта использованы номера 1000–1027.
extra_experiments.json: основные СМО и дополнительные проверки.
warm_interval_experiments.json и paired_experiments.json: остальные серии.
1019_samples.csv и 7004_samples.csv — реальные выборки, записанные WRITE в GPSS.
Графики и аппроксимации построены обработкой этих результатов; Python не моделировал системы.
system1_demo.gpr и closed_histogram_demo.gpr — стандартные отчёты отдельных
демонстрационных прогонов GPSS. Усреднённые таблицы отчёта основаны на реестрах серий.
Старые sim.py, results.json и отчёт без суффикса _GPSS относятся к предыдущей версии.
Они не используются в новом отчёте.
